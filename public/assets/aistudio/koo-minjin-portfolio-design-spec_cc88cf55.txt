## 1. 기존 포트폴리오 정밀 분석

### 1-1. 지금 잘 되어 있는 것 (살릴 것)

1. **이야기 구조가 분명합니다.** 프로젝트 01은 상황 → 행동 → 의미 → 결론으로 네 컷을 해석해 두었고, 이 구조는 그대로 웹 스크롤 연출에 쓸 수 있습니다.
2. **색채 근거가 있습니다.** 프로젝트 02는 원본 픽셀에서 팔레트를 뽑아 초반(COOL & DARK)과 후반(WARM & SOFT)을 비교했습니다. 이 포트폴리오에서 가장 강한 자산입니다.
3. **차분한 톤이 일관됩니다.** 베이지 바탕, 세리프 본문, 금색 포인트가 직무와 어울립니다.
4. **원본 순서를 밝혔습니다.** "최종본 · 원본 읽기 순서: 상단 왼쪽부터" 같은 안내는 신뢰를 줍니다.

### 1-3. 정리해야 할 내용 (정보)

- **AI 도구 표기**: 제작 지원 도구로만 씁니다. NovelAI는 이미지 생성 도구라서 사용 범위를 함께 밝혀야 합니다. `[NovelAI 사용 범위 확인 필요]`

## 2. 디자인 방향

### 2-1. 2026 트렌드 중 이 포트폴리오에 맞는 것만 골랐습니다

| 트렌드 | 적용 방식 |
|---|---|
| 에디토리얼 세리프 + 산세리프 혼용 | 한글 제목은 명조(감성), 본문은 Pretendard(가독성), 영문 강조는 이탤릭 세리프 |
| 스크롤 스토리텔링 | 페이지 전체가 하나의 이야기 곡선을 따릅니다(2-2) |
| 키네틱 타이포그래피 | 헤드라인이 글자 단위로 흐려졌다 선명해집니다 |
| 벤토 그리드 | Skills, Awarded 카드를 크기가 다른 상자로 배치합니다 |
| 질감과 노이즈 | 종이 질감 + 얇은 필름 그레인. 디지털 느낌을 덜어냅니다 |
| 부드러운 커서·마이크로 인터랙션 | 노란 점 커서가 어둠 속 빛으로 시작해 마지막 해가 됩니다 |
| 접근성 우선 모션 | `prefers-reduced-motion`이면 연출을 끄고 정적 레이아웃으로 보여줍니다 |

피하는 것: 형광색 그라데이션, 과한 글래스모피즘, 3D 오브제, 설명 없는 자동 재생 영상. 작품이 가려지면 안 됩니다.

### 2-2. 감정 곡선 (페이지 전체 설계도)

```
온도
따뜻 ┤                                         ╭────── Awarded ─── Experience ─ Contact(해)
     │                                    ╭────╯
중간 ┤                  Project 01 ───╮  ╱  (Project 02 후반)
     │      About ─────╯             ╲╱
차가움┤ Hero ────╯                 (Project 02 초반: 가장 어둡고 긴장)
     └─────────────────────────────────────────────────→ 스크롤
```

- Hero와 About은 어둡고 조용하게 시작합니다.
- Project 01은 낮 빛 같은 중간 톤입니다(종이 위 네 컷이 잘 보이도록).
- **Project 02에서 일부러 가장 어두운 곳으로 한 번 내려갔다가**, 스크롤을 따라 따뜻한 색으로 올라옵니다. 이 구간이 사이트의 클라이맥스입니다.
- 이후는 따뜻하고 부드러운 톤으로 끝납니다.

## 3. 색상 시스템

### 3-1. 기본 팔레트 (프로젝트 02 팔레트를 브랜드 색으로 승격)

사이트 색은 새로 만들지 않고, 본인 작품에서 뽑은 색만 씁니다.

**COOL & DARK**

| 토큰 | HEX | 용도 |
|---|---|---|
| `--ink-900` | `#0B0B0B` | Hero 바탕, 가장 어두운 구간 |
| `--wine-900` | `#281214` | About·Project 02 시작 바탕 |
| `--wine-700` | `#530B12` | 붉은 글로우, 긴장 포인트(큰 면, 장식용) |
| `--moss-700` | `#3B453E` | Project 01 바탕 |
| `--grey-500` | `#808080` | 보조 선, 비활성 |

**WARM & SOFT**

| 토큰 | HEX | 용도 |
|---|---|---|
| `--brown-700` | `#714E2F` | 따뜻한 구간의 보조 글자, 링크 |
| `--sand-300` | `#CFB083` | 전환 중간색, 라벨, 선 |
| `--sun-400` | `#FFD557` | **단 하나의 포인트색.** 커서, 버튼, 해 |
| `--cream-100` | `#FFEDD0` | 따뜻한 구간 바탕, 어두운 구간의 본문 글자 |
| `--cream-50` | `#FFF7CB` | 마지막 구간 바탕, Hero 제목 글자 |

### 3-2. 스크롤 단계별 색 (Scroll Temperature Stages)

| 단계 | 섹션 | `--bg` | `--fg` | `--accent` | 비고 |
|---|---|---|---|---|---|
| S1 | Hero | `#0B0B0B` | `#FFF7CB` | `#FFD557` | 붉은 글로우 `#530B12`가 배경에서 천천히 호흡 |
| S2 | About | `#281214` | `#FFEDD0` | `#CFB083` | |
| S3 | Project 01 | `#3B453E` | `#FFF7CB` | `#CFB083` | 작품 패널(흰 종이)이 돋보이는 톤 |
| S4a | Project 02 시작 | `#0B0B0B` | `#FFEDD0` | `#FFD557` | 가장 어두운 지점 |
| S4b | Project 02 끝 | `#CFB083` | `#281214` | `#714E2F` | 스크롤 진행 50~60% 지점에서 글자색 반전 |
| S5 | Awarded | `#FFEDD0` | `#281214` | `#714E2F` | |
| S6 | Experience & Skills | `#FFF7CB` | `#281214` | `#714E2F` | |
| S7 | Contact | `#FFF7CB` | `#281214` | `#FFD557` | 하단에 노란 해가 떠오름 |

### 3-3. 색 사용 규칙

1. **포인트색은 `#FFD557` 하나뿐입니다.** 한 화면에 두 곳 이상 넣지 않습니다.
2. 글자와 바탕의 명도 대비는 본문 4.5:1 이상, 큰 제목 3:1 이상입니다. 단계 전환 지점(S4a→S4b)은 글자색을 바꿔 대비를 유지합니다. **Figma에서 모든 조합을 대비 검사 플러그인으로 확인하세요.**
3. `#530B12`와 `#808080`은 글자색으로 쓰지 않습니다(장식·선·면 전용).
4. 그림자는 검정 대신 바탕색보다 한 단계 어두운 색으로 만듭니다(예: `rgba(40,18,20,.25)`).
5. 그라데이션은 두 색 사이 전환(위 표)과 Hero 글로우 외에는 쓰지 않습니다.
6. 이미지 위 글자는 반드시 반투명 바탕(`rgba(11,11,11,.55)`)이나 그라데이션 스크림을 깝니다.

### 3-3b. CSS 변수

```css
:root {
  /* palette */
  --ink-900:#0B0B0B; --wine-900:#281214; --wine-700:#530B12;
  --moss-700:#3B453E; --grey-500:#808080;
  --brown-700:#714E2F; --sand-300:#CFB083; --sun-400:#FFD557;
  --cream-100:#FFEDD0; --cream-50:#FFF7CB;

  /* live theme (JS가 스크롤에 따라 바꿉니다) */
  --bg: var(--ink-900);
  --fg: var(--cream-50);
  --accent: var(--sun-400);
  --line: color-mix(in srgb, var(--fg) 18%, transparent);
  --muted: color-mix(in srgb, var(--fg) 62%, transparent);

  /* motion */
  --ease-out: cubic-bezier(.16,1,.3,1);
  --ease-inout: cubic-bezier(.65,0,.35,1);
  --ease-cut: steps(1, end);            /* 컷 전환용: 보간 없는 딱 끊김 */
  --dur-fast:160ms; --dur-base:320ms; --dur-slow:640ms; --dur-scene:1200ms;
}
body { background: var(--bg); color: var(--fg); transition: none; }
```

## 4. 타이포그래피

### 4-1. 폰트 (모두 무료·상업 이용 가능)

| 역할 | 폰트 | 굵기 | 이유 |
|---|---|---|---|
| 한글 제목(Display) | **Noto Serif KR** | 300 / 500 / 700 | 명조 계열이라 이야기·서정의 느낌. 웹폰트로 안정적입니다. |
| 한글 본문·UI | **Pretendard Variable** | 400 / 500 / 600 | 작은 글자도 또렷하고 숫자·영문과 잘 맞습니다. |
| 영문 강조(Accent) | **Instrument Serif** (Italic 포함) | 400 | 우아한 이탤릭. 제목 속 영어 한두 단어에만 씁니다. |
| 라벨·메타 | **JetBrains Mono** | 400 / 500 | 섹션 번호, 연도, HEX 코드, 캡션 |

대체 폰트: Noto Serif KR → `Nanum Myeongjo`, Instrument Serif → `Fraunces`.
`font-display: swap`, 필요한 글자 서브셋만 불러옵니다.

### 4-2. 크기 규칙 (유동 스케일)

| 토큰 | 용도 | 크기 | 줄간격 | 자간 |
|---|---|---|---|---|
| `display-xl` | Hero 이름·헤드라인 | `clamp(3.5rem, 9vw, 9rem)` | 1.02 | -0.03em |
| `display-lg` | 섹션 제목 | `clamp(2.25rem, 5vw, 4.5rem)` | 1.12 | -0.025em |
| `display-md` | 카드 제목 | `clamp(1.5rem, 2.4vw, 2.25rem)` | 1.25 | -0.02em |
| `body-lg` | 리드 문장 | `clamp(1.125rem, 1.4vw, 1.375rem)` | 1.7 | -0.01em |
| `body` | 본문 | `1rem` (16px) | 1.75 | 0 |
| `caption` | 캡션·설명 | `0.875rem` | 1.6 | 0 |
| `label` | 번호·라벨(Mono, 대문자) | `0.75rem` (12px) | 1.4 | +0.08em |

### 4-3. 한글 조판 규칙

1. 모든 한글 텍스트에 `word-break: keep-all; overflow-wrap: break-word;`를 적용해 단어 중간에서 줄이 끊기지 않게 합니다.
2. 제목은 `text-wrap: balance;`, 본문은 `text-wrap: pretty;`.
3. 한 줄 길이는 본문 **34~42자**(한글 기준). 최대 너비 `38em`.
4. 한 문장은 45자 안팎으로 끊습니다. 문단은 2~3문장 이내.
5. 제목의 영문 단어만 Instrument Serif Italic으로 바꾸고 색은 `--accent`를 씁니다. 한 제목에 한 번만 사용합니다.
6. 마침표와 말줄임표는 한글 문장에서도 일관되게 씁니다. `...` 대신 `…`.
7. 굵게는 `600`까지만 씁니다. 700 이상은 Display 명조에서만 씁니다.
8. 대문자 라벨(`ABOUT`, `PROJECT 01`)은 Mono + 자간 +0.08em로 통일합니다.

### 4-4. 타이포 예시

```html
<h1 class="display-xl">
  짧은 이야기에,<br>
  마음의 <em class="accent-italic">temperature</em>를 입힙니다.
</h1>
```

> 위 예시처럼 영문 한 단어만 섞습니다. 본문 카피에서는 영문을 섞지 않습니다.

## 5. 레이아웃 · 그리드 · 간격

| 항목 | 데스크톱(≥1200) | 태블릿(768~1199) | 모바일(<768) |
|---|---|---|---|
| 컬럼 | 12 | 8 | 4 |
| 좌우 여백 | 64px | 40px | 20px |
| 거터 | 24px | 20px | 16px |
| 최대 너비 | 1280px | 100% | 100% |

- 간격 토큰: `4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 160`.
- 모서리: 작품 이미지는 **2px**(원고 종이 느낌), 버튼은 **999px**(알약), 카드는 **12px**.

- 작품 이미지는 항상 원본 비율을 지킵니다. `object-fit: cover`로 자르지 않습니다(썸네일 제외).
- 모든 이미지에 `width/height`를 지정해 레이아웃 흔들림(CLS)을 막습니다.

### 5-1. 고정 UI

- **상단 내비게이션**(좌측 `KOO MINJIN`, 우측 섹션 링크 5개 + `PDF`): 스크롤을 내리면 숨고, 올리면 나타납니다. 배경은 `--bg`의 80% + 블러 12px.
- **우측 세로 진행 표시**: 현재 섹션 번호(01~07)와 얇은 선. 현재 온도 색을 따라갑니다.
- **좌하단 온도 표시(작은 장식)**: `COOL ──●── WARM` 형태. 스크롤 위치에 점이 이동합니다. 사이트 콘셉트를 설명해 주는 장치입니다.

## 6. 모션 규칙

### 6-1. 공통 원칙

1. 모션은 **이야기를 돕는 곳에서만** 씁니다. 작품을 읽는 구간에서는 움직임을 줄입니다.
2. 움직이는 속성은 `transform`, `opacity`, `clip-path`만 씁니다(성능).
3. 진입 연출은 한 번만 재생합니다(`once: true`). 올릴 때 반복하지 않습니다.
4. 컷 전환은 **보간 없이 딱 끊기게**(`steps(1)`) 해서 만화의 컷 이동 느낌을 냅니다. 그 외 요소는 `--ease-out`으로 부드럽게 움직입니다.
5. `prefers-reduced-motion: reduce`이면 5번 항목의 대체안을 씁니다(6-4).

## 11. 접근성 체크

- 색 대비: 3-3의 규칙대로 모든 조합 검사. 전환 중간(S4 50% 부근)도 육안으로 확인합니다.
- 키보드: 모든 버튼·카드·슬라이더 핸들에 포커스 표시. 슬라이더는 ←/→ 키로 조작.
- 스크린리더: 분할한 제목은 `aria-label`에 원문. 장식(그레인·글로우·커서)은 `aria-hidden`.
- 모션: `prefers-reduced-motion`을 존중합니다. 깜빡임은 3회/초 이하.
- 이미지: 작품마다 구체적인 `alt`. 효과음(`멍!!`)은 alt에 문자로 적습니다.
- 언어: `<html lang="ko">`, 영문 구간에는 `lang="en"`.
- 민감한 주제 작품은 열기 전 안내(7장 6번).
